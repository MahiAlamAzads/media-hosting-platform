# Full Bootstrap frontend rewrite

This patch replaces the complete `apps/web/src` tree with a Bootstrap 5.3 dashboard and authentication frontend.

Included:
- Responsive fixed desktop sidebar
- Mobile offcanvas navigation and bottom navigation
- Bootstrap cards, forms, tables, alerts, badges and utilities
- Landing page and complete auth pages
- Dashboard, media library/detail, folders/detail, chunked upload
- Usage, audit logs, account, security and API keys
- Existing backend API contracts retained

No backend, database, migration, `.env` or storage files are changed.
